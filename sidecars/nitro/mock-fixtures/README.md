# Mock Nitro attestation fixtures

Test fixtures for `tee-nitro-v1`, generated by `../gen-mock-fixtures.sh`.

- `root.pem` / `leaf.pem` / `leaf-key.pem` form a MOCK certificate chain.
  They are **not** the AWS Nitro Enclaves root and are **not** secrets; the
  leaf private key is committed deliberately so the demo prover can sign
  COSE_Sign1 attestation documents.
- `untrusted-root.pem` is a second throwaway root used by negative tests.
- `pcrs.json` holds MOCK PCR values (`sha384("mock-pcr{i}")`) that the
  verifier pins per `circuitHash`. They do not measure any real enclave image.

Do not reuse these fixtures outside this demo.
